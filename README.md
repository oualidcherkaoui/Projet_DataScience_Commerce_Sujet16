# Pack de projets Data Science — Commerce international

- `Catalogue_40_Projets_Commerce_International.md` : tableau et 40 fiches détaillées ; source/URL et réserves.
- `Guide_Binomes_14_Jours.pdf` : 14 jours, jalons, barème.
- `Template_Projet_DataScience_Colab.ipynb` : squelette à compléter, sans solutions.
- `rapport_projet_template.tex` / `.pdf` : rapport étudiant compilable, résultats laissés vides.
- `requirements.txt` : dépendances usuelles.

**Overleaf :** Nouveau projet > téléverser `rapport_projet_template.tex` > pdfLaTeX > Compiler. Remplacer les indications en bleu. Les fichiers images réels doivent être téléversés puis appelés via `\includegraphics`.

**Sources :** la page de documentation est vérifiée, mais les volumes téléchargés des 40 cas ne le sont pas ; la preview Comtrade est plafonnée. Contrôler disponibilité avant la remise des sujets.
